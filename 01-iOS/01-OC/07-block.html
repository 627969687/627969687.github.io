5. block的类型 ​

类型存储区域MRC环境调用copy后
__NSGlobalBlock__data没有访问auto变量无变化
__NSStackBlock__栈访问auto变量拷贝到堆区，类型变为__NSMallocBlock__，auto变量的引用计数+·
__NSMallocBlock__堆__NSStackBlock__调用了copyauto变量的引用计数再次+1

5.1 block的copy ​

  1. ARC环境下block自动copy到堆上的几种情况：
    1. block作为函数返回值
    2. block被强指针引用
    3. 作为GCD API和系统的一些对象方法时
  2. ARC为什么要给block自动copy到堆上：
    1. 避免局部的auto变量未被调用就释放
  3. 无论ARC、MRC都建议@property (copy, nonatomic) void (^block)(void);这样去定义属性
objc
#import <Foundation/Foundation.h>
#import "TKPerson.h"

typedef void (^TKBlock)(void);
int main(int argc, const char * argv[]) {
    @autoreleasepool {
        TKBlock block;
        {
            TKPerson *person = [[TKPerson alloc] init];
            person.age = 10;
            int age = 10;
            block = ^{
                NSLog(@"---------%d", person.age);
            };
        }
        /*
	        1. 如果是MRC，person一旦过了作用域就会被释放
	        2. ARC自动拷贝到堆区，person引用计数+1，避免了无法访问的问题
        */
        block();
        NSLog(@"------");
    }
    return 0;
}

	NSLog("%@",blockSelf);
	blockSelf = nil;
};

__weak typeof(self)weakSelf = self
self.block = ^{
	NSLog("%@",weakSelf);
